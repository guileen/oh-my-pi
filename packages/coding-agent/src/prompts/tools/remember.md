Record one long-term memory line for this session.

`remember({"line":"…"})` appends one sentence that survives a later context cut. Nothing is deleted: the line stays in the stream for the rest of the day, and the harness re-injects it after the next cut.

Write only what the repository cannot tell you and what will change a later decision: a surprising measurement, a convention that must not be re-derived, a disproved path and why, an incident lesson, a structural blocker, a user constraint. Never restate code structure, API names, file lists, or todo detail.

Keep it under 200 characters. The hard limit is 400; a longer line is rejected and must be rewritten. At most 20 lines per day; beyond that, merge or select.
